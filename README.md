# Soil Map

## Overview

GIS project focused on soil mapping and visualization using QGIS.

The project includes a soil map with thematic classification and a legend describing the mapped soil types.

## Result

![Soil map](images/soil_map.png)

## Software

* QGIS

## Methods

* Spatial data processing
* Thematic mapping
* Visualization of soil types
* Map composition and legend design

## Note

The original QGIS project is only partially preserved, as some source layers were lost. The final map is available as an image and represents the completed visualization result.
